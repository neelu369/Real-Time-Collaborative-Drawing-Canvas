# Collaborative Canvas

## How to Run

1. `npm install`
2. `npm start`
3. Open [http://localhost:3000](http://localhost:3000) in multiple browsers

## Test with Multiple Users

- Open the app in two (or more) browsers or tabs
- Draw, erase, undo/redo in real time

## Limitations

- No persistence (refresh loses drawing)
- Usernames = socket IDs
- Very simple conflict logic

## Time Spent

- ~3 hours minimal implementation, extra for comments/docs.
